# Contractor App — Draft Audit (consolidated) — 2026-06-08

**Artifact:** Google AI Studio frontend draft "Timeless Jobs" (`/tmp/timeless-jobs-draft`, mock data, pre-backend).
**Panel (Pattern C — 7 independent perspectives):** Clifford (read) · build/QA agent · Cleo (independent CEO) · auditor-fair-work · auditor-mobile-abandonment · expert-field-service-ops · auditor-general-operational.

## VERDICT (unanimous): 🔴 NO-GO to wire the backend as-is → ✅ GO after a bounded fix pass

The draft is an **excellent UI shell on a v1.0 (pre-hardening) data spine**. The expensive work (screens, states, brand, Fair-Work-correct confirm flows, component library) is done and done well — **keep it, don't rebuild.** Every defect is concentrated in the data/state/seam layer + the missing v1.1 features + field-hardening, and all are cheaper to fix now (against mocks) than after wiring.

**Root cause (one line):** the draft was generated from the **v1.0 prompt — before Cleo's v1.1 hardening** — so it faithfully implements the *old* spec. Its `types.ts` is the v1.0 shape; that single fact cascades into most findings.

## ✅ What's GOOD — keep, do not touch
- Clean component split; all core screens; **builds green** (0 TS errors, 0 vulnerabilities, 0 build warnings).
- Brand palette exact (`index.css`); mobile-first; one primary action per screen; confirm-before-commit sheets.
- **Fair-Work copy mostly clean** — penalty-free decline (best-practice), offer-language, no countdown, no "call customer" button, no roster/timesheet/payslip.
- **No-contact holds** — zero customer phone/email anywhere; `customer_name` shows only *after* accept.

## 🔴 The master fix-checklist (deduped across all 7 lenses) — do BEFORE wiring

### UNIT 1 — Spine swap (do FIRST; unblocks everything) · ~1–1.5 days · [architecture, cleo, field-ops]
1. **Replace `types.ts` with the PRD §9 shapes.** Move `pay→sub_pay`, `part_label`, `scheduled_at` onto **Assignment** (not Job); `required_photos`→per-SKU `PhotoRequirement[]`; add `client_idem_key`, `work_days`, `current_day`, `reference_photos`, `problem`; align both enums to the schema.
2. **Delete the invented `'booked'` status** (threaded through 7+ sites — `types.ts:12,20`, `Home`, `JobDetail`, `mockApi`). It's not in the schema enum → would violate DB inserts. Make **"Booked" / "Awaiting time" / "Paused"** *derived UI labels* from `status` + `scheduled_at` + `problem`.
3. **Collapse the dual/triple source of truth** (Zustand store + `mockApi.ts:69` mutating array + page-local `data`). One owner of server state; `availableJobs`/`bookedJobs` become pure caches.
4. **Add `lib/api.ts` = the typed §10 seam.** Route ALL reads/writes through it (kill direct `mockApi` imports in `JobDetail/JobAcceptConfirm/CapturePhotos`); add env-driven base URL + auth-token injection. → "wire Supabase" becomes *one new file + flip an import*.
5. **Strip AI-Studio cruft:** remove `@google/genai`, `express`, `dotenv`, `@types/express`, `esbuild`, `tsx`; rename `react-example`→`timeless-jobs`; replace `.env.example`/`metadata.json`/`README`/`index.html` title. **Turn on `tsconfig` `strict`**; add a top-level **error boundary**; type the two `: any` payloads; wire `Profile.tsx` to `getProfile()` (kill the hardcode).

### UNIT 2 — Missing locked features · [fair-work, field-ops, cleo, mobile]
6. **🔴 Hand-back path (A6) — Fair-Work BLOCKER.** Add route + store action + mock endpoint + a "Hand back" button on the booked-job screen → confirm sheet. Penalty-free, distinct from Decline. *(The Fair-Work auditor's gating item — an app that lets a sub accept but never hand back reads as employment under s15AA.)*
7. **🔴 Per-SKU photo slots + ADD the "during" phase + enforce the gate.** Recipes are per-SKU AND three-phase (before/**during**/after) — e.g. FBP-01 needs 4 "during". Rebuild `CapturePhotos` from `PhotoRequirement[]`; **disable "Mark done" until each SKU's per-day minimums exist** (currently always enabled, `JobDetail.tsx:180`). Photos = payment evidence.
8. **🔴 Multi-day Day1/Day2** — Day 2 locked until Day 1 photos uploaded (FBP = 2-day).
9. **🟠 Make "I have a problem" actually pause the job** (currently a no-op, `store.ts:104`) + **branch asbestos to a hard STOP** (distinct from other reasons) + show the "Paused — office notified" banner that disables on-day actions.
10. **🟠 Edge states:** "This job is no longer available" (expired/taken — don't let a sub accept a dead offer); **"Awaiting time"** after availability submit (don't flip to "Booked" with a blank time → no-show risk).

### UNIT 3 — PWA + field-hardening · [build, mobile, cleo]
11. **🔴 Make it a REAL PWA** — add `vite-plugin-pwa` + manifest + icons + service worker; **persist jobs + captured photos** (localStorage/IndexedDB) so a cold reopen works, `CapturePhotos` works without visiting Home first, and **photos survive a reload** ("a photo is never lost"). Today "working from cache" is a lie (no cache exists).
12. **🔴 Fix tap targets ≥48px — the Undo button FIRST** (the *entire* accidental-accept safety net is ~22px in a 5-sec snackbar). Then back buttons (~24px ×4 screens), snackbar X, "Retake".
13. **🔴 Fix contrast + inputs:** the **pay amount is gold `#e7c08b` on white = 1.7:1 (fails WCAG)** → use navy. Raise all inputs ≥16px (kills iOS auto-zoom); add `autoComplete`/`inputMode`/`autoCapitalize` to login; dial back the all-caps 8–12px micro-type for legibility.
14. **🟠 Render the missing states:** Home `error` + a distinct **offline** message (not "no jobs available" — that reads as "no work"); SignIn bad-credentials; add `aria-label`s on icon-only buttons.

### UNIT 4 — Copy + brand finish · [fair-work, cleo]
15. **🟠 Soften the accept copy** — `JobAcceptConfirm.tsx:68-72` "Ready to commit? / you commit to performing" → "Accept this job? You're agreeing to take it on." + the quiet "you can hand it back" line. (Final wording → both-CEO Rule 8.)
16. **Load Inter** (declared in CSS but no font link in `index.html`); decide Material Symbols vs keep `lucide-react` (lucide is fine — acceptable swap); fix the `<title>`.
